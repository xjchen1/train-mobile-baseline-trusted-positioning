# 第三方源码与项目修改说明

## RTKLIB 来源与许可

本仓库含 RTKLIB 源码副本。原始版权声明及许可文件保留在 `c_src/original/LICENSE.txt`、`c_src/original_audit/LICENSE.txt` 和 `c_src/relative_cv/LICENSE.txt`。再发布源码或二进制时，按相应许可保留版权声明、条件和免责声明。随包的第三方二进制如有独立许可，需单独核对；本仓库不提交编译二进制。

## 源码变体

- `c_src/original/`：通用四组对照的基础实现。
- `c_src/original_audit/`：在 RTKLIB 基础代码上增加研究过程审计记录的构建变体；主要涉及 `src/postpos.c`、`src/rtkpos.c` 和新增的 `src/research_audit.c/.h`。
- `c_src/relative_cv/`：相对 CV 研究实现。在 RTKLIB 基础上扩展相对运动状态、预测和相关输入检查，并加入研究过程审计记录。改动涉及 `app/consapp/rnx2rtkp/rnx2rtkp.c`、`src/options.c`、`src/postpos.c`、`src/rtkcmn.c`、`src/rtklib.h`、`src/rtkpos.c`；新增 `src/relmotion.c/.h` 和 `src/research_audit.c/.h`。

逐行差异见 `原版至相对CV.patch`。源码文件顶部保留的 RTKLIB 原版权属信息仍适用于其中的上游代码；新增项目代码和本地修改不应被误认为是 RTKLIB 上游发布内容。

## 复现边界

仓库不包含原始 RINEX / NovAtel 数据、路线地图、运行输出或编译程序。使用者需要提供自己的输入数据并在本机重新构建。历史实验包和策略22候选代码未纳入本仓库。
